# kip-releases
## Public download link

`releases/latest/download/KIP.apk` serves **1.0.199**, the starter build, from now on.
Future releases must **not** be marked "Latest" and must **not** carry a `KIP.apk` asset,
so this public link stays on 1.0.199. Newer builds reach supporters through `latest.json`
and a valid supporter key only.
